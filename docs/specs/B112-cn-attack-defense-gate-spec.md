## 2. ★预注册判据（裁定归 Codex，F002）

| 判据 | 门槛 | 阈值的独立理由（不由观测值反推） |
|---|---|---|
| **主判据 A（全样本风险）** | V1 − V0 全样本 MaxDD 改善 **≥ +5pp** | cn_attack 全样本 MaxDD −58.3%（B070）；改善 <5pp（相对基数 <9%）不值得引入机制复杂度与误判成本 |
| **主判据 B（OOS 风险）** | V1 − V0 OOS MaxDD 改善 **≥ +3pp** | 沿用 B106 组合层门槛（ΔMaxDD ≥ +3pp），不新设 |
| **副判据 C（代价上限）** | 全样本 ΔCAGR **≥ −2.0pp** 且 ΔSharpe **≥ −0.05** | B082 防守腿代价 3.15pp 被判 mixed——本批收紧至 2pp；Sharpe −0.05 为噪声容差带 |
| **裁定规则** | 主 A+B 全过且副 C 不越界 → **GO**；主判据任一不过 → **NO-GO**；数据/执行缺陷致不可判 → **INCONCLUSIVE**（须指明缺哪一环） | — |

- 两 mode（pure/quality）**各自独立下裁定**（允许一个 GO 一个 NO-GO）。
- 并列披露（不作判据）：全样本/OOS 的 CAGR、Sharpe、MaxDD、年换手、成本、分年收益、
  闸触发月数与逐月状态（全部留痕进产物）。
- **H7 同款：Generator 只算不裁**；产物不得出现结论性措辞（复用 B110/B111 的机器禁词判据）。
